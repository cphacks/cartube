# CarTube

Watch YouTube on your car's infotainment screen, on CarPlay and Android Auto, without a jailbreak.

## About

CarTube brings YouTube playback to Apple CarPlay and Android Auto. On iOS, it installs
through sideloading (no jailbreak required). On Android, it installs directly.

Learn more and get the latest version at [cartube.app](https://cartube.app).

## Platforms

- Apple CarPlay (iOS, sideload install, no jailbreak)
- Android Auto

## Installation

Full, current install instructions for both platforms are maintained at
[cartube.app](https://cartube.app), since install steps change with iOS and Android
Auto policy updates more often than this repo does.
